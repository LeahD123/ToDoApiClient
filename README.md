TodoList Client Application 🎨

A client-side TodoList application built with React.js and styled using pure CSS3.
The application communicates with a backend server built with .NET Minimal API, providing a clean and lightweight task management experience.

🚀 Features
📝 Display and manage daily tasks
⚡ CRUD operations implementation (Create, Read, Update, Delete)
🔗 Integration with backend REST API services
🔄 Automatic task loading using useEffect
⏳ Asynchronous API calls for efficient data fetching and updates
🎨 Responsive and clean UI built with React.js and CSS3

📌 Project Highlights
Built as a lightweight client-side application connected to a Minimal API backend
Implemented CRUD functionality through reusable service functions
Organized application structure with separation between UI and service logic
Used asynchronous operations to improve performance and user experience
Dynamic rendering of tasks immediately upon application load


🧠 Architecture Overview
App.js manages application state and CRUD actions
useEffect is used for initial data fetching
Service layer handles all API communication and business logic
Backend communication implemented through RESTful requests
